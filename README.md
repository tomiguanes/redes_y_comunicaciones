# Redes y Comunicaciones

Repositorio de estudio y práctica para la materia **Redes y Comunicaciones** de 3er año de la carrera **Análisis de Sistemas** en el **Instituto Superior Juan XXIII**.

---

## 📚 Estructura del Repositorio

- **Material Teórico y Cátedra:**
  - `Capitulo1.pdf` - Introducción a las redes y comunicación de datos
  - `Capitulo2_1.pdf` - Capa de Aplicación
  - `Capitulo3.pdf` - Capa de Transporte (TCP / UDP)
  - `Capitulo4_1.pdf` - Capa de Red y Ruteo
  - `Capitulo5.pdf` - Capa de Enlace y Física
  - `Computer Networking A Top-Down Approach.pdf` - Bibliografía principal (Kurose & Ross)

- **Práctica y Diagnóstico:**
  - `Practico_Subnetting.pdf` & `Subneteo.pdf` - Ejercicios de direccionamiento IP y máscaras de subred
  - `ComandosRedWindows.pdf` & `COMANDO_NETSTAT_Win-Linux.pdf` - Comandos de diagnóstico de red
  - `laboratorio/` - Consignas y topologías de ruteo directo y ruteo completo

- **Entorno de Aprendizaje Interactivo (`/teach`):**
  - `MISSION.md` - Objetivo pedagógico y definición de éxito
  - `RESOURCES.md` - Fuentes de conocimiento y comunidades
  - `NOTES.md` - Notas de seguimiento y preferencias de estudio
  - `lessons/` - Lecciones interactivas HTML estructuradas
  - `reference/` - Documentos de referencia rápida y cheat sheets
  - `learning-records/` - Registro incremental de aprendizajes y conceptos consolidados
  - `assets/` - Estilos compartidos y componentes reutilizables
